Introduction

Base URL: http://site_id.snet.localhost:15080/

This documentation aims to provide all the information you need to work with Site API.

To make POST request you need to send a csrf token with the request. It is handled automatically with most of JS frameworks

https://laravel.com/docs/13.x/csrf#csrf-x-csrf-token

As you scroll, you'll see code examples for working with the API in different programming languages in the dark area to the right (or as part of the content on mobile). You can switch the language used with the tabs at the top right (or from the nav menu at the top left on mobile).

Authenticating requests

This API is not authenticated.

Helper APIs

CSRF cookie

requires authentication

Return an empty response simply to trigger the storage of the CSRF cookie in the browser.

Example request:
curl --request GET \
    --get "http://site_id.snet.localhost:15080/site_api/v1/csrf-cookie"
const url = new URL(
    "http://site_id.snet.localhost:15080/site_api/v1/csrf-cookie"
);



fetch(url, {
    method: "GET",
}).then(response => response.json());
import requests
import json

url = 'http://site_id.snet.localhost:15080/site_api/v1/csrf-cookie'
response = requests.request('GET', url, )
response.json()
$client = new \GuzzleHttp\Client();
$url = 'http://site_id.snet.localhost:15080/site_api/v1/csrf-cookie';

Site API Query Endpoint

requires authentication

Endpoint to query local or peer database

Example request:
curl --request POST \
    "http://site_id.snet.localhost:15080/site_api/v1/query_endpoint" \
    --header "Accept: application/json" \
    --header "Content-Type: application/json" \
    --data "{
    \"query_parameters\": \"Json body of query parameters - {\\\"table\\\":\\\"posts\\\",\\\"where\\\":[[\\\"title\\\",\\\"!=\\\",\\\"excluded_title\\\"]]}\"
}"

const url = new URL(
    "http://site_id.snet.localhost:15080/site_api/v1/query_endpoint"
);

const headers = {
    "Accept": "application/json",
    "Content-Type": "application/json",
};

let body = {
    "query_parameters": "Json body of query parameters - {\"table\":\"posts\",\"where\":[[\"title\",\"!=\",\"excluded_title\"]]}"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());
import requests
import json

url = 'http://site_id.snet.localhost:15080/site_api/v1/query_endpoint'
payload = {
    "query_parameters": "Json body of query parameters - {\"table\":\"posts\",\"where\":[[\"title\",\"!=\",\"excluded_title\"]]}"
}
headers = {
  'Accept': 'application/json',
  'Content-Type': 'application/json'
}

response = requests.request('POST', url, headers=headers, json=payload)
response.json()
$client = new \GuzzleHttp\Client();

    $url,

        'headers' => [

        'json' => [
            'query_parameters' => 'Json body of query parameters - {"table":"posts","where":[["title","!=","excluded_title"]]}',
