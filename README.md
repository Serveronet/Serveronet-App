## About Serveronet

Serveronet P2P Websites - Free and Uncensorable,
Decentralized, Cryptographic Peer 2 Peer Network of Sites.

- Can run a client on your PC or a Web Server
- Suitable for public internet sites as well
- Free and open source
- Site Developer friendly 


## Getting Started

Go to Serveronet Site for **downloads** and **instructions** how to deploy -

## Project status

Project is in the alpha stage. Do not use in production environments.  
Bacause this Serveronet Client is a web application and requires security updates author promises up to a year of security patches to the underlaying stack.
