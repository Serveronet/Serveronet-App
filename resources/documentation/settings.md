# Client Settings
## Introduction
Client Settings are separated into 2 groups. Advanced and basic.
Do not change Advanced setting unless you know, what you are doing.

## Common Settings
Settings that you might want to adjust at some point:
- Tor client config - tor_address, tor_port - Adjust if Tor client is on a separate machine, is installed directly or using a Tor Browser
- IPFS Client - ipfs_address, ipfs_read_only - Adjust IPFS address. Use a public IPFS gateway which are read only.
- Port Forward - port_forwarding_enabled - Enable Port forwarding functionality of a router
- Automatic Update - automatic_update_enabled - Update your client automatically. It's recommended on for the security reasons.
- Opennic API Address - opennic_api_address_ip - Update Opennic IP address to the current one when DNS might be blocked
